# ACKword downloads

ACKword is a desktop editor for paginated documents with text, images, tables and references.

| Platform | Installer |
| --- | --- |
| Ubuntu, 64-bit Intel or AMD | `ackword-<version>-linux-amd64.deb` |
| Windows, 64-bit Intel or AMD | `ackword-<version>-win-x64.exe` |

Choose the installer for your platform from [GitHub Releases](https://github.com/DARE-WORKS/AckWordReleases/releases). Each installer comes with a SHA-256 checksum.

On Ubuntu, open the `.deb` in your package manager or run `sudo apt install ./ackword-<version>-linux-amd64.deb` with the actual filename. On Windows, run the `.exe` to install ACKword for your user account.
